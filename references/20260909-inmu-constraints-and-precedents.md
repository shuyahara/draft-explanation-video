# 淫夢コンテンツ解説動画の制約調査（YouTube規約・先行事例・権利・倫理）

- 対象: Issue #32「ネット民はなぜ淫夢コンテンツに熱狂するのか」（ずんだ人文学）
- 調査日: 2026-09-09
- 前提: 元作品の映像・画像不使用、語録は差別的でないものに限定、出演者の実名・特定情報は出さない。この方針での適法性・許容性を判断する調査（台本執筆は対象外）。

## 1. YouTube規約の該当条項と当てはめ

**ヌードと性的なコンテンツ**: 「性的満足を与えることを意図した露骨なコンテンツは許可されない」（性器等の描写、ポルノ、フェティッシュ描写を禁止）。例外は「教育・ドキュメンタリー・科学・芸術（EDSA）が主目的で必要性・脈絡がある場合」。出典: [Nudity & Sexual Content Policy](https://support.google.com/youtube/answer/2802002?hl=ja)
→当てはめ: 映像・性的行為の描写を一切含まない設計なら本条項に抵触しない。**リスク低**。

**年齢制限**: 「性行為を誘う動画」「視聴者の性的興奮を意図したポーズ」「タイトル・サムネイル・メタデータの非常に冒とく的な表現」が基準。出典: [年齢制限のあるコンテンツ](https://support.google.com/youtube/answer/2802167?hl=ja)
→当てはめ: 映像がなければ直接該当しないが、**タイトル・サムネイルに露骨な語録を使うと年齢制限リスクが上がる**。

**広告掲載ガイドライン（収益化）**: 「デリケートな社会問題＝トラウマ・虐待関連や視聴者が不安を感じるトピック」は限定的収益化の対象。「冒頭・大部分に冒とく的表現」も非対応要因。出典: [広告掲載に適したコンテンツのガイドライン](https://support.google.com/youtube/answer/6162278?hl=ja)
→当てはめ: 「元がアダルトビデオ」「出演者の人権問題に触れる」点は社会問題寄りに分類されうる。**限定的収益化（黄色マーク）のリスクは中程度**。

**EDSA例外の要件**: 例外は(1)人物特定・内容説明など「基本的事実情報」(2)非難・反対意見・風刺の明示(3)危険行為の非模倣呼びかけ、のいずれかを**動画本編（音声・映像）で**示す場合のみ成立し、概要欄・固定コメントでの説明は理由にならない。出典: [How YouTube evaluates EDSA content](https://support.google.com/youtube/answer/6345162?hl=ja)
→当てはめ: 本企画はEDSAに頼る必要が薄い設計だが、念のためナレーションで「文化現象の解説であり性的内容を見せる意図はない」という文脈を音声内に明示すると安全。

**同性愛を題材にする点**: 性的指向自体を制限する条項はない（むしろヘイトスピーチポリシーの保護属性）。**リスクは倫理面にあり規約面ではない**。
**通称での実在人物言及**: 規約に実在人物への特別規定は明記されないが、ハラスメントポリシー・名誉毀損の一般法理に留意（要確認）。実名・特定情報を出さない既定方針の遵守が前提。

## 4. 権利面

- **権利者**: 株式会社コートコーポレーション（COAT、ゲイビデオ制作会社）。出典: [Wikipedia](https://ja.wikipedia.org/wiki/%E7%9C%9F%E5%A4%8F%E3%81%AE%E5%A4%9C%E3%81%AE%E6%B7%AB%E5%A4%A2)
- **削除要請**: COATが二次創作動画に組織的な削除要請・訴訟を行った記録は確認できず。確認できたのは探偵事務所を通じた迷惑行為参加者への特定・被害届通知（動画解説への権利行使ではない）。**要確認**: 語録紹介動画への個別の著作権侵害主張の有無。
- **パロディの著作権上の位置づけ**: 日本法に米国型フェアユースのような明文のパロディ規定はなく、二次創作は常に侵害リスクを抱えるのが弁護士解説の一般論。出典: [弁護士法人小寺・松田法律事務所](https://kmlaw.jp/2022/06/07/%E3%80%90%E3%83%91%E3%83%AD%E3%83%87%E3%82%A3%E3%81%A8%E8%91%97%E4%BD%9C%E6%A8%A9%E3%81%AE%E3%81%9B%E3%82%81%E3%81%8E%E5%90%88%E3%81%84%E3%80%91%EF%BC%88%E5%BC%81%E8%AD%B7%E5%A3%AB%E3%80%80%E3%80%80/)。映像・画像不使用なら複製・翻案に該当しにくく**リスク低**。ただし語録の長い一節をそのまま反復引用する構成は避けるべき。
- **出演者のプライバシー**: 2016年、大島薫氏が出演者「野獣先輩」の特定・捜索企画を告知し炎上の末中止。特定・実名暴露が高リスクである明確な先例。出典: [経緯（はてな匿名ダイアリー）](https://anond.hatelabo.jp/20160819030423)、[大島薫 Wikipedia](https://ja.wikipedia.org/wiki/%E5%A4%A7%E5%B3%B6%E8%96%AB)。**実名・特定情報を出さない方針はこの先例に照らして必須**。

## 5. 倫理面の論点と配慮案

1. 出演者の性的行為を嘲笑対象にすること自体が人格否定（松岡宗嗣氏: 「同性愛蔑視のネットミーム」「出演者の人権侵害」）。出典: [X投稿](https://x.com/ssimtok/status/1890026902326542345) → 性的行為・容姿を笑う語録は使わず、受容過程の分析に徹する。
2. 「ネットミーム」「カルチャー」の呼称が差別的背景を隠蔽するという批判 → 批判が存在すること自体を動画内で明言し両論併記する。
3. 同性愛への偏見とコミュニティの逸脱行動（誹謗中傷・特定）は区別すべき（木村すらいむ氏、note「アジア的優しさ」）→ 対象を性的指向ではなく「ネット文化がどう変容・拡散させたか」という現象そのものに置く。
4. 出演者特定・晒し行為は社会的に断罪された前例あり（大島薫氏の件）→ 実名・特定情報は一切出さず通称・役名のみで語る。
5. コミュニティの迷惑行為（下北沢集合等）が現在も継続（KAI-YOU記事）→ 現地情報・現在進行形の行為の実況的紹介はせず、過去の事象として距離を置く。
6. 若年層への影響（松岡氏: 生徒が蔑視ミームで笑っていた証言）→ 語録を無批判に列挙せず、視聴者への一言の注意喚起を入れる。
7. 権利者・出演者の権利とパロディ・言論の自由のバランス → 映像・画像不使用を徹底し、著作物の実質的利用（反復引用）を避ける。

## 6. 結論: リスク評価と避けるべき表現

| 項目 | リスク | 根拠 |
|---|---|---|
| 削除・BAN | 低 | 性的描写・映像不使用なら禁止条項に直接抵触しない |
| 年齢制限 | 低〜中 | タイトル・サムネイルの語選び次第で上がる |
| 収益化制限 | 中 | 「デリケートな社会問題」属性で黄色マークの可能性 |
| 著作権侵害 | 低 | 映像不使用・反復引用回避で限定的。COATの過去対応は未確認 |
| 名誉・プライバシー侵害 | 中（対策で低） | 大島薫氏の事例が示す高リスク。既定方針の徹底が前提 |
| 差別・炎上批判 | 中 | LGBT当事者からの批判が現に継続中。両論併記で緩和可能だが消えない |

**総合評価: 中程度のリスク**。方針（映像不使用・語録限定・特定情報排除）を守れば規約違反・著作権・プライバシーのリスクは低く抑えられるが、**収益化制限と「差別的では」という批判のリスクはゼロにならない**。表現の質（現象分析に徹する語り口、両論併記、出演者を人格として扱う配慮）で緩和すべきリスクであり、企画を止める理由には当たらない。

**避けるべき表現トップ5**:
1. 出演者の実名・現在の生活・特定情報、特定行為の詳細描写
2. 出演者の性的行為・容姿・性的指向自体を笑いの対象にする語り口
3. 元作品の映像・画像・語録の長い反復引用
4. タイトル・サムネイルへの露骨な語録・卑猥表現
5. 現在も続く迷惑行為（下北沢集合等）の実況的・扇動的紹介

## 7. 要確認事項

- 先行動画の具体的な再生回数・登録者数・年齢制限有無（本調査では取得不能）。
- 淫夢解説動画がBAN・収益化停止・年齢制限になった一次資料の有無。
- COATが語録紹介動画に個別の著作権侵害を主張した具体事例。
- ねとらぼ・文春オンライン等大手Webメディアの単独記事の有無。
- YouTubeのハラスメント・いじめポリシーが通称での実在人物言及をどう評価するかの条文。
