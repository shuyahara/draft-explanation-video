# チャンネルアイコン案（ずんだ人文学）

コンセプト: ずんだもんの公式立ち絵（坂本アヒル氏、改変可）の顔はそのまま使い、Pillow で描いた
小物（学者帽・眼鏡・髭）を重ねる。生成AIは不使用（キャラの顔は描き換えていない）。

生成スクリプト: `make_icon.py`（実行は script-to-video の venv の python）。
```
C:\Users\shuya\Projects\script-to-video\.venv\Scripts\python.exe make_icon.py
```

## 出力

| ファイル | 内容 |
|---|---|
| `icon-1.png` / `icon-1-circle.png` | 案1: 角帽＋丸眼鏡＋白いあごひげ |
| `icon-2.png` / `icon-2-circle.png` | 案2: 丸いドクターキャップ（タム帽）＋半月眼鏡＋白いふさふさの口髭＋あごひげ |
| `icon-3.png` / `icon-3-circle.png` | 案3: 角帽（案1と同じ）＋丸眼鏡（案1と同じ）＋黒いちょび髭（軽め） |

`icon-N.png` は 800x800 RGB（YouTube アイコン用）。`icon-N-circle.png` は円形表示（YouTube の
実際の見え方）を確認するための検品用プレビュー（RGBA、円の外側は透明）。

## 各案の詳細

### 案1（icon-1）
- 表情: `smug.png`（得意顔＝学者っぽい）
- 帽子: 角帽（mortarboard）。黒い菱形の板＋頭に沿う黒い帽体＋金色のボタン＋右に垂れる金タッセル。
- 眼鏡: 丸眼鏡。細い黒フレーム、薄い水色がかった白のレンズ塗り＋ハイライト線、両目の中心に合わせた。
- 髭: 白いあごひげ（口の少し下から顎にかけての小さな goatee 型）。口（ω の形）は隠していない。

### 案2（icon-2）
- 表情: `normal.png`（目を開けた自然な顔。半月眼鏡越しに視線が見える構図を意図）
- 帽子: 丸いドクターキャップ（タム帽/ベレー風）。ふくらんだ黒い丸帽＋頭に接する帯＋ひだの
  ステッチ線＋てっぺんの金ボタン。
- 眼鏡: 半月眼鏡（下がった位置）。`ImageDraw.chord` で下半分だけのレンズ形状にし、金縁で
  「読書メガネを鼻先にかけている」印象にした。
- 髭: 白いふさふさの口髭＋あごひげ（輪郭に沿って小さな円を連ねてもこもこ感を出した）。
  `normal.png` は口が小さい線のため、口髭で覆われる（案2は口を隠す設計）。

### 案3（icon-3）
- 表情: `smug.png`（案1と同じ）
- 帽子: 角帽（案1と同一デザイン・同一関数）
- 眼鏡: 丸眼鏡（案1と同一）
- 髭: 黒い小さなちょび髭のみ（あごひげなし）。「軽め」にする指示に沿い、装飾を最小限にした。
  口は隠していない。

## 位置合わせに使った座標

`smug.png` / `normal.png` はいずれも 823×1513 の透過 PNG で、同じ体型・同じ顔位置のリグ違い
（表情差分）。以下は元画像座標系（左上が原点）で、`_grid_*.png`（グリッド線入りの一時ファイル、
確認後に削除済み）を目視計測して確定した値。`make_icon.py` の定数として残している。

| ランドマーク | 座標 (x, y) |
|---|---|
| 左目中心（画面向かって左） | (237, 325) |
| 右目中心（画面向かって右） | (432, 320) |
| 目の半径目安 | 58px |
| 顔の中心線 x | 345 |
| 口（ω）の中心 | (345, 403) |
| 顎先 | (345, 438) |
| 帽子の中心 x（アンテナの谷間） | 350 |
| 帽子の帯が頭に接する y | 90 |

小物は上記の座標を基準に、4倍解像度（`SS=4`）のレイヤーへ描いてから `LANCZOS` で縮小し、
アンチエイリアスを効かせている。

## 背景・縁取り

- 背景は script-to-video の紙芝居モードと同じ黒板（`Kamishibai()` 既定色 `#2E4A3C`）を
  `render_board_plate` / `compute_stage` で実際にレンダリングし、拭き跡・周辺減光つきの
  正方形を切り出して 800×800 に縮小したもの（無地の代用ではなく実際の黒板テクスチャ）。
- 立ち絵の白い縁は `add_paper_outline`（既定の `puppet_outline_px=12`）をそのまま使用。
  紙人形を切り抜いたような見た目にしている。

## 合成の仕組み（つまずいた点と対処）

- 帽子の頂点（角帽の板の先端、タム帽の丸い頭頂）は元スプライトの `y<0` にはみ出す設計だった
  ため、素朴に実装すると小物レイヤーの上端でクリップされ、角帽が「平らに切れた台形」に、
  タム帽が「黒い箱」に見える不具合が起きた（1〜2回目の生成で発生・目視で発見）。
  対処として、元スプライトの上に `TOP_MARGIN=160px` の透明な余白を持つ拡張キャンバスを
  作ってから小物を描き、最終キャンバスへの変換時にその余白ぶんを補正するよう修正した
  （`make_icon.py` の `TOP_MARGIN` / `compose_character` / `build_icon` 参照）。
- タム帽のひだ線は `ImageDraw.arc` の角度指定を誤り、帽子の**上**にはみ出す不具合があった
  （PIL の角度系は 0°=3時方向・時計回りのため、下半分の弧は `start=20, end=160` が正しい）。
  修正して帽体の下側にステッチ状のひだとして収めた。

## 妥協点・検品メモ

- 顔・目・口・髭が隠れていないか、①〜③の観点（顔の要素が隠れていない／小物が顔に合って
  浮いていない／円で切ったときに帽子が極端に欠けない）を `icon-N-circle.png` で確認済み。
  円形トリミングでは角帽の左右の角（板の左端・右端の頂点）がわずかに切れるが、中央の頂点・
  ボタン・タッセル本体は残るため「極端な欠け」ではないと判断した。
- 案2の白いふさふさ髭は `normal.png` の口を覆う設計（口の位置に髭を置く＝指示の許容範囲内）。
  案1・案3の髭は口を覆わない位置にした。
- 小物のスタイル（フラットな塗り＋濃い輪郭線）は立ち絵の線画に寄せたが、Pillow の図形描画
  ベースのため、公式イラストほどの曲線の滑らかさ・筆致の揺らぎは再現していない（アイコンの
  縮小表示では気にならない範囲と判断）。
- 3案とも同じ黒板背景・同じ縁取り設定で統一し、キャラの表情差分（`smug`/`normal`）と小物の
  組み合わせだけを変えている。
